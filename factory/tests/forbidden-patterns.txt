# Patterns no tracked file of the kit may contain (factory/tests/forbidden-words.sh).
# `re <ERE>`  a pattern written out (shapes: tokens, private addresses, internal host names).
# `b64 <base64 of an ERE>`  a pattern kept encoded, so that names of private hosts, repositories,
#   organisations and people do not appear in the kit even here. Matching ignores case.
# Add a name: printf '%s' 'name' | base64, and a line `b64 <that>`.
# `allow <base64 of a string>`  a public string that holds a forbidden name (the kit's own repository
#   slug): it is taken out of a line before the patterns are matched again.
